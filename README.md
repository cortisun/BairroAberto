# OpenNeighborhood — The Sims 4

An experimental script mod that explores seamless access to ordinary neighboring
residential lots, inspired by **The Sims 3**.

**Not finished / Não está pronto.** See [LEIAME.md](LEIAME.md) for Portuguese
build and safety instructions. The current prototype can capture furnishings
while visiting a neighbor and *attempt* to preview one object after returning
to the active lot; it cannot load an entire home or eliminate loading screens.

Version history is preserved with Git tags `v0.2.0` through `v0.5.0`.
The earliest source supplied for this project was v0.2.0.
